# 山水报价查询

安徽山水智元产品报价表的只读搜索前端。原表不会被修改，分类、商品索引和 10 月特价轮播都由独立数据快照生成。

## 功能

- 单一商品分类筛选：显卡、主板、存储、显示器、一体机、机箱、电源、散热/风扇、外设、套餐
- 按型号、规格、分类和备注搜索
- 显卡型号后的“套提 / 套题”内容自动拆分为备注
- 10 月特价套包首页轮播，图片从原表商品图导出一份
- 价格排序、复制单条报价
- 响应式桌面和移动端布局

## 运行

```bash
npm install
npm run dev
```

打开 `http://localhost:4173/`。

生产构建：

```bash
npm run build
npm run preview
```

## 从原表同步

前提：本机 Chrome 已登录可查看该金山文档。

```bash
npm run sync
```

同步程序会：

1. 复制当前 Chrome 登录态的临时副本
2. 以只读方式打开金山文档
3. 读取 13 个工作表的单元格值
4. 导出 10 月特价套包图片
5. 重新生成 `src/data/catalog.json`

它不会写入原表，也不会保存 Chrome 密码。临时浏览器目录在同步完成后删除。

## 数据文件

- `data/source-snapshot.json`：原始工作表矩阵快照
- `src/data/catalog.json`：清洗、分类后的可搜索数据
- `public/deals/package-1.png` 至 `package-6.png`：10 月特价轮播图

## 当前版本边界

这是只读搜索 MVP。原表更新后运行一次 `npm run sync` 即可刷新。后续如果要做 3–5 分钟自动同步，可以在本机或 fnOS 上定时运行同步命令。
